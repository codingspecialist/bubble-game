# enemy 적군 만들기

종류: 기능
배울 것: 혼자 걷는 물체, 벽에서 돌아서기

## 할 일
- S1 적군 셋이 바닥 둘, 오른쪽 아래 발판 하나에 왼쪽을 보고 서 있다
- S2 적군은 키를 누르지 않아도 바라보는 쪽으로 걷는다
- S3 적군이 벽에 닿으면 돌아서서 반대쪽으로 걷는다
- S4 적군이 발판 끝에서 걸어 나가면 아래로 떨어져 선다
- S5 장 끝 코드를 ex10 패키지에 남긴다

## 흐름
게임 루프 -> 적군마다 걷기 -> 벽이면 돌아서기 -> 중력으로 떨어지기 -> 발판에 서기

## 안 하는 것
- 적군과 부딪히기: enemy-trap, game-over 장
- 적군 점프: 안 만듦
