# floor-gravity 발판과 중력

종류: 기능
배울 것: Rectangle 목록, 중력, 착지

## 할 일
- S1 바닥과 발판 다섯 개가 벽돌로 보인다
- S2 플레이어가 공중에서 시작해 아래로 떨어진다. 떨어질수록 빨라진다
- S3 떨어지던 플레이어가 발판이나 바닥에 닿으면 그 위에 선다
- S4 발판 끝에서 걸어 나가면 아래로 떨어진다
- S5 장 끝 코드를 ex06 패키지에 남긴다

## 흐름
게임 루프 -> 좌우 이동 -> 중력으로 속도 더하기 -> 아래로 이동 -> 발판에 닿으면 그 위에 세우기

## 안 하는 것
- 점프: player-jump 장
