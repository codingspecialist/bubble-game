# player-move 좌우 이동

종류: 기능
배울 것: KeyAdapter, Timer 게임 루프, Direction enum, Lombok

## 할 일
- S1 왼쪽, 오른쪽 화살표를 누르면 플레이어가 그쪽으로 움직인다
- S2 키를 누르고 있는 동안 끊기지 않고 부드럽게 움직이고, 떼면 멈춘다
- S3 플레이어가 움직이는 쪽을 바라본다
- S4 장 끝 코드를 ex04 패키지에 남긴다

## 흐름
키 누름 -> 방향 기억 -> 게임 루프가 16ms마다 움직임 -> 키 뗌 -> 멈춤

## 안 하는 것
- 벽에서 멈추기: wall-stop 장
- 위아래 이동: 안 만듦. 위는 점프 장에서 쓴다
