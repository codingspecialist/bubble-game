# bubble-shoot 물방울 쏘기

종류: 기능
배울 것: 리스트로 여러 물체 갱신

## 할 일
- S1 스페이스를 누르면 플레이어 자리에 물방울이 생긴다
- S2 물방울은 플레이어가 바라보는 쪽으로 300만큼 날아간다
- S3 다 날아간 물방울은 천장까지 천천히 떠오른다
- S4 물방울은 벽을 넘지 않는다
- S5 여러 번 쏘면 물방울 여러 개가 따로 움직인다
- S6 장 끝 코드를 ex08 패키지에 남긴다

## 흐름
스페이스 -> 물방울 만들어 목록에 넣기 -> 게임 루프가 목록의 물방울을 모두 움직임 -> 옆으로 날기 -> 위로 뜨기

## 안 하는 것
- 물방울 사라지기: bubble-pop 장
- 물방울 터트리기, 밟고 오르기: 안 만듦
