# game-over 게임오버

종류: 기능
배울 것: 게임 루프 멈추기, 소리 한 번 재생

## 할 일
- S1 플레이어가 갇히지 않은 적군에 닿으면 모든 움직임이 멈춘다
- S2 플레이어가 쓰러진 그림으로 바뀐다
- S3 화면 가운데 맨 앞에 GAME OVER가 보인다
- S4 배경음악이 멈추고 게임오버 소리가 한 번 나온다
- S5 장 끝 코드를 ex15 패키지에 남긴다

## 화면
+------------------------------------------+
| 버블 게임                                |
+------------------------------------------+
|  벽돌                              벽돌  |
|                                          |
|            GAME OVER                     |
|                                          |
|       적군 쓰러진펭귄                    |
+------------------------------------------+

## 흐름
게임 루프 -> 적군과 닿음 -> 갇히지 않았으면 게임오버 -> 루프 멈춤 -> 쓰러진 그림 -> GAME OVER 보이기 -> 배경음악 끄고 게임오버 소리

## 안 하는 것
- 다시 시작: 안 만듦. 창을 닫고 다시 실행한다
- 목숨 여러 개: 안 만듦
