# player-jump 점프

종류: 기능
배울 것: 위로 향하는 속도, 발판 아래에서 올라타기

## 할 일
- S1 위 화살표를 누르면 플레이어가 위로 뛰었다가 중력으로 내려온다
- S2 발판에 서 있을 때만 뛴다. 공중에서는 다시 뛰지 않는다
- S3 발판 아래에서 뛰면 발판을 뚫고 올라가 그 위에 선다
- S4 장 끝 코드를 ex07 패키지에 남긴다

## 흐름
위 화살표 -> 서 있는지 확인 -> 위로 속도 주기 -> 중력이 속도를 줄임 -> 내려오다 발판에 서기

## 안 하는 것
- 머리가 발판에 부딪히기: 안 만듦. 발판은 아래에서 뚫고 올라간다
- 두 번 뛰기: 안 만듦
