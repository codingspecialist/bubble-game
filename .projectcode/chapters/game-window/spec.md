# game-window 게임 창과 배경

종류: 기능
배울 것: JFrame, 절대 배치, JLabel 배경

## 할 일
- S1 실행하면 제목이 버블 게임인 창이 화면 가운데 뜬다
- S2 창을 닫으면 프로그램이 끝난다
- S3 창 전체에 동굴 배경 그림이 깔리고 창 안 크기가 1000x640이다
- S4 장 끝 코드를 ex02 패키지에 남긴다

## 화면
+------------------------------------------+
| 버블 게임                          _ □ X |
+------------------------------------------+
|                                          |
|            동굴 배경 그림                |
|              1000 x 640                  |
|                                          |
+------------------------------------------+

## 흐름
실행 -> 창 만들기 -> 배경 깔기 -> 창 보이기

## 안 하는 것
- 창 크기 바꾸기: 안 만듦. 크기를 고정한다
