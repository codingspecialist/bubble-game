# enemy-trap 적군 가두기

종류: 기능
배울 것: Rectangle intersects, 상태 바꾸기

## 할 일
- S1 날아가는 물방울이 적군에 닿으면 적군이 물방울에 갇힌 그림으로 바뀐다
- S2 적군을 가둔 물방울은 바로 사라진다
- S3 갇힌 적군은 걷지도 떨어지지도 않고 그 자리에 머문다
- S4 이미 갇힌 적군에 다른 물방울이 닿아도 아무 일이 없다
- S5 장 끝 코드를 ex12 패키지에 남긴다

## 흐름
게임 루프 -> 물방울마다 적군과 겹치는지 확인 -> 겹치면 적군을 갇힘 상태로 -> 물방울 터짐 -> 갇힌 적군은 멈춤

## 안 하는 것
- 갇힌 적군 터트리기: enemy-pop 장
- 갇힌 적군이 떠오르거나 풀려나기: 미룸
