# enemy-pop 갇힌 적군 터트리기

종류: 기능
배울 것: 리스트에서 적군 지우기, 클리어, 화면 맨 앞에 놓기

## 할 일
- S1 플레이어가 갇힌 적군에 닿으면 적군이 터져 화면에서 사라진다
- S2 터진 적군은 목록에서 빠진다
- S3 갇히지 않은 적군에 닿으면 아직 아무 일이 없다
- S4 적군을 모두 터트리면 화면 가운데 맨 앞에 CLEAR!가 보인다
- S5 장 끝 코드를 ex13 패키지에 남긴다

## 화면
+------------------------------------------+
| 버블 게임                                |
+------------------------------------------+
|  벽돌                              벽돌  |
|                                          |
|              CLEAR!                      |
|                                          |
|           펭귄                           |
+------------------------------------------+

## 흐름
게임 루프 -> 적군마다 플레이어와 겹치는지 확인 -> 갇힌 적군이면 터트려 지우기 -> 목록이 비면 CLEAR! 보이기

## 안 하는 것
- 갇히지 않은 적군에 닿으면 지기: game-over 장
- 다음 스테이지: 미룸
